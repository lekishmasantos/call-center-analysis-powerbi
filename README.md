# Call Center Analysis Dashboard

## Project Overview

This project analyzes call center data to identify the most common reasons patients and doctors' offices contact the organization.

The goal of the analysis was to understand call volume, identify recurring issues, and determine which areas may need process improvements.

The Power BI dashboard includes:

* Total call volume
* Patient vs. doctor office calls
* Call reasons/categories
* Portal access issues
* Scheduling hold-time concerns
* Missing report inquiries
* Percentage breakdowns by call type
* Interactive filters and slicers

## Tools Used

* Microsoft Excel
* Power Query
* Power BI
* DAX
* Data Visualization

## Key Insights

The analysis showed that portal-related calls accounted for a significant portion of the total call volume.

The dashboard also makes it possible to compare patient and doctor-office calls and identify which issues generate the most inquiries.
